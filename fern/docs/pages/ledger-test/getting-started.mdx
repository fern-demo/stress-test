---
title: Getting started
subtitle: Set up your plant store development environment
---

Follow these steps to get your local plant store running.

<Steps>
  <Step title="Install dependencies">
    Install the Fern CLI globally:

    ```bash
    npm install -g fern-api
    ```
  </Step>

  <Step title="Initialize the project">
    Create a new Fern project in your repository:

    ```bash
    fern init
    ```
  </Step>

  <Step title="Generate documentation">
    Run the docs generation command:

    ```bash
    fern generate --docs
    ```
  </Step>
</Steps>

<Note>
  This page tests standard MDX content rendering through the ledger pipeline.
</Note>
